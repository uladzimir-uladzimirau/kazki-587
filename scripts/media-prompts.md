# KAZKI media prompts

Prompts used to generate the bundled artwork (originally produced with an AI
image/audio generator). Keep them as the reference for regenerating or
extending the asset set with any current generator.

Post-processing: `scripts/convert-media.sh` (ImageMagick + ffmpeg) converts
raw outputs into `android-kazki/app/src/main/res/`.

## Style (all covers)

> Gentle storybook gouache illustration for a Belarusian folk tale for small children. Deep navy night-blue palette with warm golden light, red and cream Belarusian embroidery (vyshyvanka) patterns on clothing, plants and borders, rowan berries, calm cozy bedtime mood, soft painterly texture, centered composition, no text, no letters.

Aspect ratio 3:4, opaque. Output name: `cover_<id>.png`.
